Next actions

  1. Define how usefulness is measured. Before building anything new, there has to be a clear way to say how useful a piece of text is for graph search, and a fair way to test any method against it.
  2. Compare with methods that do not use a graph. Some methods reach the second fact simply by searching again. Comparing with them shows how much the graph itself really adds.
  3. Build a way to predict usefulness. The goal is to tell in advance which pieces of text are worth adding to the graph, without first paying to extract links from all of them.
  4. Test it on new questions and changing documents. A selection rule is only useful if it keeps working on questions it has never seen and when the document collection changes over time.
  5. Check when the graph pays off. The last step is to find out when building and updating a graph is worth its cost compared with simpler search methods.
